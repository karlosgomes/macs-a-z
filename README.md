# MACS A...Z

Apresentações para as aulas de Matemática Aplicada às Ciências Sociais (MACS, 10.º ano), feitas com Quarto/Reveal.js.
Cada apresentação tem um exemplo introdutório, a descrição do método passo a passo e problemas resolvidos, muitos deles de Exame Nacional.

Página: https://karlosgomes.github.io/macs-a-z/
